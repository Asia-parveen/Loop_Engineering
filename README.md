# Loop Engineering Project 6: Event-driven GitHub PR Review

## Overview

An event-driven GitHub PR review workflow using OpenCode's GitHub integration.
The GitHub pull-request event triggers the review automatically without manual prompts.

## Baseline

This project contains a small Python module with passing tests.

## Setup

1. `git init` - Initialize repository
2. `opencode github install` - Install OpenCode GitHub integration
3. Create a feature branch and open a PR to trigger the workflow
